## From stuck to solved, in four stages

A grid constraint is five problems at once: technical, regulatory, commercial, financial and operational. Technology is rarely the hard part; making all five answers line up is.

| Understand | Decide | Implement | Scale and manage |
| :--- | :--- | :--- | :--- |
| Where do we really stand? Grid position, constraints, options and stakeholders. | What can actually work, and is it worth it? Routes compared, business case, a dossier your grid operator can approve. | How do we get it done? Supplier and CSP selection, tenders, contracts, negotiation with the grid operator. | How do we keep it working as we grow? Programme management, portfolio roll-out, ongoing advice. |
| *Flex Scan* | *Business Case · Second Opinion* | *Implementation support · Embedded Build* | *Ongoing advice* |

Traditional consultancies hand over a report. Generic AI agencies build software without knowing grid rules. We bring both: energy advice that ships as working software or AI agents, built in weeks inside your own systems.
